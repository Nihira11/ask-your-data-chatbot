# Data dictionary

Status: template. Complete this after selecting the dataset; do not index placeholders.

For each table, document:

- Name and purpose.
- What one row represents (for example, an order versus an order item).
- Primary key and foreign keys.
- Column names, types, meanings, and null handling.
- Allowed relationships and join keys.
- Dataset version and date coverage.

Explain the row level clearly to prevent double-counting during joins.
